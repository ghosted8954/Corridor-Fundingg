ACCESS FOR EVERYONE

Accessibility Statement

We aim to make the Corridor Funding website usable and understandable for visitors with different access needs.

Our accessibility goal

Our goal is to improve access to website information and functionality for people using different devices, assistive technologies and navigation methods.

Accessibility practices

We aim to support practices such as:

  • Clear headings and meaningful page structure.
  • Text alternatives for meaningful images.
  • Keyboard navigation for interactive controls.
  • Readable text and adequate color contrast.
  • Labels and instructions for form fields.
  • Responsive layouts for mobile, tablet and desktop screens.
  • Useful status messages for form errors and other outcomes.

Standards and testing

The website should be evaluated against the Web Content Accessibility Guidelines (WCAG) version 2.2, Level AA, as an implementation goal, with additional review for applicable legal requirements. Do not treat this statement as proof that every page currently conforms.

Known limitations

Some features, third-party services or older content may have accessibility barriers. We encourage visitors to report any problem that prevents them from accessing information or completing a task.

Request assistance

If you encounter an accessibility barrier, contact us through the available contact page. Include the page address, a description of the issue, and an alternative way to reach you if you wish. Please avoid including passwords or unnecessary sensitive information.

Ongoing improvements

Accessibility should be reviewed during development and after significant website updates. Testing should include keyboard-only navigation, screen-reader checks, zoom, color contrast and mobile usability.
